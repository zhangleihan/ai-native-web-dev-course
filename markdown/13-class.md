# 实践练习：LLM 应用：证据、结构化输出与服务端边界

## 输入与准备

使用配套实验中的模拟模型适配器、两条带来源的案例材料和诊断路由骨架；仅在接入真实服务时配置密钥。

## 已提供的实验骨架

使用本仓库[案例库实验](labs/course-lab/README.md)，按[第13讲任务单](labs/course-lab/WORKSHEETS.md)定位对应文件。先运行参考实现并解释数据流，再完成本讲增量任务。数据库与 Docker 实验需要在具备相应环境的计算机上运行。

## 操作步骤

连接 mock 路由与页面；检查结构；模拟不存在的 evidenceId 和超时；检查模式标记与错误反馈。

## 结果检查与练习成果

正常显示建议及来源；假证据被拒绝；超时不无限等待；浏览器无密钥；mock 清晰标注。

提交实现或设计产物，以及一条实际观察结果。失败时保留请求、错误信息与已排查的层级；不只提交“已完成”截图。所有实验均使用测试数据。

## 学习自检

完成练习后，检查自己能否做到：实现服务端模型适配边界；校验结构与来源；报告失败、模拟模式及调用成本。若暂时无法运行，记录缺少的依赖与错误信息，待环境具备后补做验证；阅读参考结果不能代替亲自运行。
