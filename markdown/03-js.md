## 变量与常量

声明：`let 名字`。赋值用 `=`（这是赋值，不是数学相等）。优先 `let` / `const`，**不要 `var`**（`let` 是块级作用域）。

```javascript
let myVariable = 123;
myVariable = 321;

const PI = 3;
// PI = 4; // 报错：引用不能改
const obj = { a: 3 };
obj.a = 5; // 允许：改的是对象内容，不是引用
```

对应 FDE：`industry`、`kw` 会变 → `let`（React 里是 `useState`）。`CaseItem` 的字段名、状态枚举不会改 → 当常量看。

## 数据类型

常用：`number`、`string`、`boolean`、`undefined`、`null`、对象、数组。

| 运算符 | 例子 |
|---|---|
| `+ - * / %` | `1 % 2 // 1` |
| 字符串拼接 | `'Hello' + ' ' + 'World'` |
| 模板字符串 | `` `${title} · ${industry}` `` |

陷阱：`1 + 1 === 2`，但 `'1' + '1' === '11'`，`'1' + 1 === '11'`（字符串优先）。案例 `rating` 是数字，`difficulty` 是字符串，比较时用 `===` 不要 `==`。

布尔：`true` / `false`。JS 里假值主要是 `false`、`0`、`''`、`null`、`undefined`、`NaN`，其余多为真值。

## 函数

函数是按需执行的一块代码，起描述性名字，一次只做一件事。

```javascript
function displayGreeting(name, salutation = 'Hello') {
  return `${salutation}, ${name}`;
}
displayGreeting('林知远'); // Hello, 林知远
```

`console.log` 是 **方法**（挂在 `console` 对象上）；`displayGreeting` 是自由函数。会多次用的写成具名函数；只用一次可用匿名函数或箭头函数：

```javascript
setTimeout(() => console.log('900ms 后'), 900);
```

FDE 的 `CopilotDrawer` 里那次 `setTimeout` 就是「把函数当参数」。案例过滤应抽成函数，第 10 讲才能测：

```javascript
function filterCases(cases, industry, kw) {
  return cases.filter(
    (c) =>
      (industry === '全部' || c.industry === industry) &&
      (kw === '' || c.title.includes(kw) || c.summary.includes(kw)),
  );
}
```

## 做出决定

比较：`< <= > >= === !==`。逻辑：`&&`、`||`、`!`。**严格相等 `===`** 同时比值和类型。

```javascript
if (c.goldenCase) {
  console.log('Golden Case');
} else {
  console.log('普通案例');
}

const label = c.status === '进行中' ? '继续做' : '去领取';
```

`cases/page.tsx` 里的筛选条件就是一串 `&&` / `||`。

## 数组与循环

索引从 **0** 开始。`length` 是元素个数。`push` 追加。

```javascript
const industries = ['通信运营', '智能制造', '物流供应链'];
industries[0]; // 通信运营

for (let i = 0; i < industries.length; i++) {
  console.log(industries[i]);
}
industries.forEach((name) => console.log(name));
const titles = cases.map((c) => c.title);
```

FSO / React 用 `map` 渲染列表；`filter` 做筛选。`for` 在打字游戏里用来清掉所有词的 `className`。亲手用 `for` 走一遍，才知道 `map` 替你干了什么。
