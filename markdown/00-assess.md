# 考核与授课方式

比例沿用课程大纲（与旧课介绍页一致）：

| 项目 | 占比 | 说明 |
|---|---|---|
| 课堂考勤 | 10% | 到课、参与 Golden Path / 当堂演示 |
| 课堂练习、课后练习、期中练习 | 40% | 「课后练习」；期中检查案例库走 HTTP、登录与库表是否落地 |
| 课程作业 | 50% | **1–4 人分组**：升级 FDE 平台切片（推荐），或教师同意的选题 / 参与开源项目 |

## 课程作业期望

- 能演示 Golden Path 一段（登录 → 案例 → Agent Run → 审批）且 **Network 里看得到业务 API**（后半学期）
- 有 README：如何启动、账号、未完成项（虚线要诚实）
- 密钥不进 Git；学生角色不能靠前端切换提权

## 分组

1–4 人。第 0 讲结束后在微信群报组，并在在线表格填写 GitHub 代码仓库，用于提交平时作业和课程项目，添加zhangleihan@gmail.com访问权限（见「教师、微信群与开发环境」一节的文档链接）。
