# 考核与授课方式

保持课程原有 **10% / 40% / 50%** 比例，以下为本教材配套评价量规；各次提交时间以云邮发布的教学任务为准。

| 项目 | 占比 | 评价依据 |
|---|---|---|
| 课堂考勤与参与 | 10% | 到课、当堂讨论和出口检查 |
| 课堂/课后及期中练习 | 40% | 练习占课程总分 25%，期中检查占 15% |
| 课程作业 | 50% | 1–4 人小组交付完整网络应用，并进行个人问答 |

## 平时与期中

平时练习按任务完成度 50%、验证证据 30%、原理解释 20% 评分，再折算到课程总分的25%。选修拓展不替代必做，不按功能数量奖励。

第 8 讲后检查：交互页面与 API 契约 25%、数据库持久化 25%、身份与资源授权 25%、复现说明和个人解释 25%，折算为总分15%。允许记录尚未完成项，但不能用假数据冒充已实现功能。

## 课程作业量规（组内作品满分100，再折算总分50%）

| 维度 | 分值 | 满分证据 |
|---|---|---|
| 用户任务与前端交互 | 15 | 核心任务完整，语义/键盘与错误反馈清楚 |
| API 与数据 | 20 | 契约稳定、输入校验、重启后数据保留 |
| 权限与安全边界 | 15 | 服务端授权、负向请求被拒绝、无泄露密钥 |
| AI 与受控执行 | 15 | 来源可追溯、模式透明、工具审批与失败有证据 |
| 测试与评估 | 15 | 成功/失败用例可复现，评估不夸大结论 |
| 交付与个人解释 | 20 | 启动文档10分；每位成员贡献和问答10分 |

每项按完整、部分完成、未实现分别结合实际证据给分；能运行但缺验证不得直接满分。最后一项的个人10分分别评定，其余按小组作品证据评定。模拟模型可验证系统边界，但不算真实模型质量证据；不因是否购买模型服务区别评分。

## 选题、分组与提交

1–4 人一组，可选游戏、网络应用或有可核验贡献的开源项目。需体现动态 Web/全栈能力，并提供与五项目标对应的实现；自选题的 AI 与工具功能可采用等价业务，不必复制 FDE 菜单。游戏也不能仅提交纯静态页面替代后端和数据目标。

分组信息、代码/仓库信息、README、测试或评估记录与个人贡献说明，统一按**北邮云邮教学空间**发布的要求提交；不再要求通过旧在线表格收集 GitHub 账号。非公开仓库按课程平台要求提供教师可访问的交付方式。

允许 AI 辅助。简述使用范围、一项审查或修正与验证结果；所有成员须能解释本人负责部分。不得提交密钥、真实个人数据或伪造运行证据。最终演示含一条成功路径和一条失败/拒绝路径。
