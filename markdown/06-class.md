# 课堂练习：关系数据库：约束、参数化查询与事务

## 输入与准备

教师准备 PostgreSQL 隔离库、pg 连接骨架与空迁移文件；第 5 讲 API。

## 已提供的实验骨架

使用本仓库[案例库实验](labs/course-lab/README.md)，按[第6讲任务单](labs/course-lab/WORKSHEETS.md)定位对应文件。先运行参考实现并解释数据流，再完成本讲增量任务。真实数据库与Docker验证仍需要授课机具备对应环境。

## 操作步骤

10 分钟执行 cases 迁移；15 分钟将列表与创建接入提供的 repository 骨架；10 分钟重启 API 重查；5 分钟尝试违反 CHECK 约束。

## 验收与交付

重启 API 后记录仍在；查询参数化；约束阻止非法难度；提交迁移和操作记录。

提交实现或设计产物，以及一条实际观察结果。失败时保留请求、错误信息与已排查的层级；不只提交“已完成”截图。所有实验均使用测试数据。

## 出口检查

对照以下能力逐项演示并解释：设计最少必要表；使用参数化 SQL；验证重启后数据保留和事务回滚。遇到环境阻断时记录阻断点并使用教师演示环境验证，明确区分亲自执行和观察演示。
