# 实践练习：认证与授权：把信任边界放在服务端

## 输入与准备

使用配套实验或已有项目中的登录与会话骨架，准备 A、B、admin 测试账号以及 owner_id 迁移。

## 已提供的实验骨架

使用本仓库[案例库实验](labs/course-lab/README.md)，按[第8讲任务单](labs/course-lab/WORKSHEETS.md)定位对应文件。先运行参考实现并解释数据流，再完成本讲增量任务。数据库与 Docker 实验需要在具备相应环境的计算机上运行。

## 操作步骤

跟踪身份如何到达路由；实现 owner/admin 检查；用 A 请求 B 的资源及伪造 role；检查数据库未改变。

## 结果检查与练习成果

未登录写入 401；普通用户越权 403（或统一隐藏策略）；合法操作成功；body 的 role 无效。

提交实现或设计产物，以及一条实际观察结果。失败时保留请求、错误信息与已排查的层级；不只提交“已完成”截图。所有实验均使用测试数据。

## 学习自检

完成练习后，检查自己能否做到：区分身份认证与资源授权；保护案例写操作；通过负向请求验证权限。若暂时无法运行，记录缺少的依赖与错误信息，待环境具备后补做验证；阅读参考结果不能代替亲自运行。
