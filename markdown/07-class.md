# 课堂练习：前后端集成：请求生命周期与竞态

## 输入与准备

React 工程与真实列表 API；配套实验采用同源服务，无需额外代理；准备空行业和网络断开条件。

## 已提供的实验骨架

使用本仓库[案例库实验](labs/course-lab/README.md)，按[第7讲任务单](labs/course-lab/WORKSHEETS.md)定位对应文件。先运行参考实现并解释数据流，再完成本讲增量任务。真实数据库与Docker验证仍需要授课机具备对应环境。

## 操作步骤

10 分钟接入正文 Effect；15 分钟呈现四种状态；10 分钟快速切换条件并停止 API；5 分钟解释 Network 与界面的一致性。

## 验收与交付

三个筛选参数均发往服务器；失败不显示为空列表；旧响应不覆盖新结果；清理请求。

提交实现或设计产物，以及一条实际观察结果。失败时保留请求、错误信息与已排查的层级；不只提交“已完成”截图。所有实验均使用测试数据。

## 出口检查

对照以下能力逐项演示并解释：接通真实 API；呈现加载、成功、空结果与失败；取消失效请求并说明跨源行为。遇到环境阻断时记录阻断点并使用教师演示环境验证，明确区分亲自执行和观察演示。
