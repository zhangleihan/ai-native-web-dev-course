# 实践练习：从页面到 AI 原生应用：请求链与系统边界

## 输入与准备

浏览器与任意可访问 Web 页面；FDE 平台可用时打开案例库。

## 操作步骤

写出查询需求；观察首次加载与一次筛选的 Network；画浏览器—API—数据库链；互换解释并修正。

## 结果检查与练习成果

提交请求记录与一张链路图；标注观察到的事实和尚未证实的假设。

提交实现或设计产物，以及一条实际观察结果。失败时保留请求、错误信息与已排查的层级；不只提交“已完成”截图。所有实验均使用测试数据。

## 学习自检

完成练习后，检查自己能否做到：画出一次查询的数据流；区分浏览器、服务端和数据库的职责；用可验证需求描述一个 AI 功能。若暂时无法运行，记录缺少的依赖与错误信息，待环境具备后补做验证；阅读参考结果不能代替亲自运行。
