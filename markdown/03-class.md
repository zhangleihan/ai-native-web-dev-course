# 课堂练习：现代前端基础：语义、布局与事件

## 输入与准备

正文完整 HTML 示例与浏览器；无需启动 FDE。

## 操作步骤

10 分钟运行例子并解释三个语言层；15 分钟新增行业筛选；10 分钟用键盘和窄屏检查；5 分钟注入带尖括号的标题并观察其按文本呈现。

## 验收与交付

关键词与行业组合生效；无匹配有提示；输入有 label；Tab 可达；用户文本不被解析成标签。

提交实现或设计产物，以及一条实际观察结果。失败时保留请求、错误信息与已排查的层级；不只提交“已完成”截图。所有实验均使用测试数据。

## 出口检查

对照以下能力逐项演示并解释：写出可键盘操作的案例列表；用数组方法筛选数据；用 DOM 事件更新文本。遇到环境阻断时记录阻断点并使用教师演示环境验证，明确区分亲自执行和观察演示。
