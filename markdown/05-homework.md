# 课后练习：为期末项目实现一个资源接口

## 必做

从期末项目中选择一个资源，如任务、预约或案例，完成集合、详情和创建接口，使用Express或FastAPI。先写契约再编码：列出字段类型、可写字段、校验规则、成功及失败状态。

将应用构造与启动分开。至少验证一条正常创建、一个缺失资源、三种非法输入，以及重启前后的数据行为。记录真实请求与响应，解释失败是否产生副作用；当前可使用内存数据，第6讲再引入数据库。

## 提交内容

通过北邮云邮教学空间按课程要求提交源码、依赖锁文件、相对路径启动说明、接口表和验证记录。说明所参考的外部资料和AI参与范围，解释一次自己发现并修正的问题。截图仅作辅助，不能代替请求、响应及源码。

## 自评标准

| 维度 | 可以检查的表现 |
|---|---|
| 契约 | 方法、路径、字段、状态码一致 |
| 实现 | 合法请求完成操作，非法请求不写入 |
| 结构 | 能定位路由、校验、存储和启动 |
| 验证 | 正常、缺失、校验、生命周期均有证据 |
| 理解 | 能说明框架协助了什么、自己实现了什么 |

## 选做

选择一项：增加受校验分页并定义total；实现PATCH与DELETE；为同一契约增加Python或JavaScript对照实现；将依赖分页示例整合进FastAPI。拓展后补充真实验证，不只增加菜单或注释。

## 可选：为一个资源编写OpenAPI

参照[OpenAPI教程](#/part/5/g)，为期末项目一个资源描述列表、创建与详情，明确输入必填、成功与失败响应。生成文档或类型，提交一次成功与一次失败的实际调用，并说明哪些业务规则尚未验证。以完成一条可检查链路为目标，不要求同时安装全部工具。
