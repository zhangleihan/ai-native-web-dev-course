# 课后练习：为期末项目设计并验证数据层

## 必做

选择期末项目的一个核心资源，设计数据表，列出字段类型、主键、必填和业务约束。按第五讲契约实现集合、详情、创建，使用参数化查询；数据可以先存于配套文件型引擎，也可使用独立PostgreSQL练习库。

提交一次正常写入、两种约束失败、重启后读取的证据。把建表或结构变更保存为迁移文件，说明数据库数据与前端状态的生命周期。

## 提交内容与自评

通过北邮云邮教学空间按要求提交源码、锁文件、关系图、迁移、相对路径运行说明和操作记录。使用AI时说明参考资料与参与范围，并解释一个自己检查或修正的问题。

| 维度 | 自评依据 |
|---|---|
| 建模 | 每张表有明确实体与关系，字段不无故重复 |
| 约束 | 能说明为何需要主键、非空、唯一或外键 |
| 查询 | 参数化且筛选、排序与total语义正确 |
| 生命周期 | 重启后记录仍可读，数据目录或连接配置明确 |
| 证据 | 未验证项明确，不用嵌入式结果冒充服务验证 |

## 选做

选择一项：增加多对多关系并解释JOIN行数；实现两步事务并注入失败验证回滚；增加新迁移并保留旧数据；观察索引前后执行计划。并发、备份和生产部署不要求在本讲全部完成。
