# 实践练习：综合项目：贯通一条业务链并评估结果

## 输入与准备

项目当前可运行版本、fixture、测试账号与缺口清单。

## 已提供的实验骨架

使用本仓库[案例库实验](labs/course-lab/README.md)，按[第15讲任务单](labs/course-lab/WORKSHEETS.md)定位对应文件。先运行参考实现并解释数据流，再完成本讲增量任务。数据库与 Docker 实验需要在具备相应环境的计算机上运行。

## 操作步骤

确定主线与缺口优先级；修复一个阻断；执行五类评估场景；记录剩余限制。

## 结果检查与练习成果

交付启动说明、成功/失败路径与逐条评估表；明确模拟、真实调用、未完成三种边界。

提交实现或设计产物，以及一条实际观察结果。失败时保留请求、错误信息与已排查的层级；不只提交“已完成”截图。所有实验均使用测试数据。

## 学习自检

完成练习后，检查自己能否做到：交付可重复演示的纵向功能；构建小型评估集；依据失败证据决定改进优先级。若暂时无法运行，记录缺少的依赖与错误信息，待环境具备后补做验证；阅读参考结果不能代替亲自运行。
