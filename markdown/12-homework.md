# 课后练习：AI Coding：规格、类型与人工验收

## 必做（建议 30–60 分钟）

把一个 API 数据边界加入运行时校验；若使用 TypeScript，指出编译器无法保证的外部输入。

## 提交内容

通过北邮云邮教学空间，按教师发布的任务提交代码或仓库信息、复现步骤和验证证据。使用 AI 时简述它参与的范围、你检查的内容与一次修正；不提交真实密钥或私人对话。未使用 AI 则说明人工决策过程。

## 自评标准

- 能复现本讲的核心行为，而非仅能打开页面。
- 能解释一项输入、输出或失败边界。
- 证据与实现一致，尚未验证的部分明确标注。

## 选做（不要求全部完成）

比较两种提示策略的改动范围与验证成本，不仅比较生成速度。
