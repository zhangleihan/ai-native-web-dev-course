# 课后练习：测试：从需求到可重复的失败证据

## 必做（建议 30–60 分钟）

添加一个组件错误提示测试与一条 API 回归测试；说明各自证明什么、没有证明什么。

## 提交内容

通过北邮云邮教学空间，按教师发布的任务提交代码或仓库信息、复现步骤和验证证据。使用 AI 时简述它参与的范围、你检查的内容与一次修正；不提交真实密钥或私人对话。未使用 AI 则说明人工决策过程。

## 自评标准

- 能复现本讲的核心行为，而非仅能打开页面。
- 能解释一项输入、输出或失败边界。
- 证据与实现一致，尚未验证的部分明确标注。

## 选做（不要求全部完成）

使用浏览器自动化覆盖登录到创建这一条关键路径。
