## 开发环境

- 浏览器：**Chrome**（始终打开开发者工具，Network 勾选 Disable cache）
- 编辑器：**VS Code** 或 **Cursor**
- 运行时：Node.js（平台与 API）、Python 3（打开本教材静态页）
- 本教材：`cd ai-native-web-dev-course && python3 -m http.server 8766 --bind 127.0.0.1`
- 平台：`FDE-Workspace` 下 `./start.sh` → http://127.0.0.1:3100

VS Code / Cursor 里新建 HTML 可试 `html` + Tab 展开骨架（Emmet）。第 3 讲起会用到。
