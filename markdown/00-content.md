# 核心内容

正课 **16 讲 × 2 学时 = 32 学时**。第 3 讲另含 `labs/` 里的 JS 基础、花艺瓶、打字游戏。

| 讲次 | 主题 | 对应能力（相对旧课「主要内容」） |
|---|---|---|
| 1 | AI 时代的网络应用开发 | MPA / SPA、请求链、FDE 平台地图 |
| 2 | Web 与 HTTP 原理 | GET/POST、状态码、Header |
| 3 | 现代前端基础 | HTML、CSS、JavaScript、函数、数组、DOM、事件 |
| 4 | React 与组件化 | 组件、state、列表；不再使用 jQuery 作为主线 |
| 5 | 后端与 REST API | Node、Express、JSON 资源 |
| 6 | 数据库与数据建模 | PostgreSQL；对照旧课 Sqlite / Mongo |
| 7 | 前后端集成 | fetch、CORS、三种 UI 状态 |
| 8 | 身份认证与 Web 安全 | 登录、角色、XSS/CSRF |
| 9 | 实时 Web 应用 | SSE / 轮询 |
| 10 | 测试与软件工程 | API 与组件测试 |
| 11 | Docker 与部署 | 容器、Compose、CI |
| 12 | AI Coding 与 Vibe Coding | 规格驱动、TypeScript 护栏 |
| 13 | LLM Web Application | 服务端模型、结构化输出 |
| 14 | Agentic Web Application | 工具循环、审批状态机 |
| 15 | AI-FDE 综合项目 | 可演示切片、评估集 |
| 16 | Demo Day 与架构复盘 | 把请求链讲圆 |

旧课条目 Bootstrap、jQuery 不再单列；UI 以 Ant Design + 原生 CSS 为主。需要组件库时在项目中按需引入，不要为了「会一个库名」另起一套作业。

教材打开：本仓库 `ai-native-web-dev-course`，浏览器访问 http://127.0.0.1:8766 。平台 POC：`FDE-Workspace` 的 `./start.sh` → http://127.0.0.1:3100 。
