# 核心内容与学时

课程导读不另计学时。以下 16 讲合计 **32 学时**。每讲按 90 分钟设计；第 16 讲采用演示专用安排。

| 讲次 | 主题 | 学时 |
|---|---|---|
| 1 | 从页面到 AI 原生应用：请求链与系统边界 | 2 |
| 2 | HTTP 契约：资源、方法与失败响应 | 2 |
| 3 | 现代前端基础：语义、布局与事件 | 2 |
| 4 | React：组件、状态与单向数据流 | 2 |
| 5 | Express API：校验、资源与错误边界 | 2 |
| 6 | 关系数据库：约束、参数化查询与事务 | 2 |
| 7 | 前后端集成：请求生命周期与竞态 | 2 |
| 8 | 认证与授权：把信任边界放在服务端 | 2 |
| 9 | 实时反馈：轮询、SSE 与连接生命周期 | 2 |
| 10 | 测试：从需求到可重复的失败证据 | 2 |
| 11 | 部署与持续集成：可复现环境和数据生命周期 | 2 |
| 12 | AI Coding：规格、类型与人工验收 | 2 |
| 13 | LLM 应用：证据、结构化输出与服务端边界 | 2 |
| 14 | Agent：工具执行、审批与运行状态 | 2 |
| 15 | 综合项目：贯通一条业务链并评估结果 | 2 |
| 16 | 演示与复盘：用证据说明系统能力 | 2 |

## 四个阶段与检查点

1. 第 1–4 讲：能解释请求链并完成交互页面。
2. 第 5–8 讲：案例 API、数据库与权限贯通；第 8 讲后进行期中检查。
3. 第 9–12 讲：异步反馈、测试、环境交付与 AI 辅助开发。
4. 第 13–16 讲：带证据的 AI 建议、受控执行、评估与综合演示。

主线使用 HTML/CSS/JavaScript、React、Node/Express 和 PostgreSQL；已有 Next 项目可以等价实现。不同时要求多种后端、状态管理或数据库框架。Bootstrap、jQuery 不再独立成章；组件库按项目需要使用。

本讲后续“考核与授课方式”给出评分量规。“教师、微信群与开发环境”保留课程联系和云邮提交入口说明。

## 配套实验入口

第4–15讲使用同一套[案例库实验](labs/course-lab/README.md)。下载/查看目录中的运行说明后，在实验目录执行 `npm ci --ignore-scripts`、`node scripts/init-env.mjs`、`npm run dev`，访问说明中的本机地址。教材静态服务不提供实验API。

按[分讲任务单](labs/course-lab/WORKSHEETS.md)完成增量修改，用[评估模板](labs/course-lab/EVALUATION_TEMPLATE.md)记录实际证据。默认模拟模型不需要付费账号。
