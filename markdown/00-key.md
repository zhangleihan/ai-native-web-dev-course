## 定位与先修

面向具备基本编程经验、希望理解并实现现代 Web 应用的学生。课前能使用文件、终端、变量、条件和函数即可；不要求已掌握 React、数据库或 AI 框架。JavaScript 不熟悉者先阅读第 3 讲补充页。

贯穿案例为 AI-FDE 工程管理实训平台的一个最小切片：案例查询与持久化 → 登录和资源授权 → 服务端诊断建议 → 受控工具执行。也可采用独立案例库或自选业务，不把完整平台改造作为入门门槛。

## 目标与达成证据

| 课程目标 | 对应讲次 | 可观察的达成证据 |
|---|---|---|
| 1. 掌握基本静态网页设计 | 3 | 语义结构、布局、键盘可操作的案例页 |
| 2. 理解动态网页前端实现 | 3–4、7 | 正确管理状态、事件和异步反馈 |
| 3. 了解 Web 后端实现 | 2、5–6、8 | API 契约、持久化、服务端授权 |
| 4. 能实现简单全栈应用 | 7、9–11、15–16 | 可复现主线、测试与部署说明 |
| 5. 能将 LLM/Agent 接入 Web | 12–16 | 带来源的建议、受控工具、失败和评估证据 |

## 学习路径与范围

正文、课堂练习和课后必做覆盖核心目标；外部阅读、花艺瓶/打字游戏、多 Agent、MCP 实接、长期记忆、复杂本体、向量库与云集群为拓展。没有模型账号可使用明确标记的模拟适配器完成系统能力验证，真实模型质量需另行评估。

讲义中的完整例子会标明运行方式；标注“片段”或“伪代码”的内容需放入已有骨架，不能声称复制即可运行。教师应在授课前准备 React、数据库、认证、容器与 Agent 骨架，避免学生在一节课中从零搭建多个系统。

每讲按“读懂原理 → 跑一个例子 → 改一个行为 → 验证失败边界”推进。AI 可以协助实现，但学生须能解释代码、复现结果并承担验证责任。
