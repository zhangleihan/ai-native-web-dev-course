## 课程概要

在代码实现层面学习 Web 应用开发：前端页面、后端服务、数据读写，以及把大模型与 Agent 做成系统功能。从技术实现角度看清信息系统怎么跑起来——浏览器要什么、服务器回什么、数据存在哪、模型在哪调用。

贯穿案例是 **AI-FDE 工程管理实训平台**（仓库 `FDE-Workspace/web`）：把前端 Fake Data POC 做成可持久化、可认证、可跑真实模型的 AI 原生 Web 系统。Golden Case 为「通信网络故障处理」。

## 课程目标

1. **掌握基本的静态网页设计**：HTML 结构、CSS 布局、语义化与无障碍（第 3 讲花艺瓶等）。
2. **理解动态网页的前端实现**：JavaScript、DOM 与事件、React 组件与状态（第 3–4、7 讲）。
3. **了解 Web 服务的后端实现**：HTTP/REST、Express（或等价）、关系库、认证授权（第 2、5、6、8 讲）。
4. **能够实现简单的全栈 Web 应用**：前后端集成、测试、容器与部署（第 7、10、11 讲）。
5. **能把 LLM / Agent 接到 Web 里**：服务端调用、SSE、工具循环与审批（第 12–15 讲），而不是只做一个聊天框。

## 授课方式

- 课堂讲原理与重点技术，对着平台源码和 Network 面板看
- 实时写代码、课堂练习；规格由人写，实现可交给 Agent，验收必须人做
- 以系统性的 Web 应用（FDE 平台升级）为主，技术点练习（花艺瓶、打字游戏、health/echo）为辅

## 一次请求经过哪里

```
浏览器
  → DNS（域名到 IP）
  → 服务器
  → 数据库 / 模型网关
  → 返回 HTML、CSS、JavaScript 或 JSON
  → 页面或 SPA 更新
```

前端：HTML、CSS、JS（以及 React）。后端：服务框架、数据库、鉴权，以及本课的模型与工具调用——密钥不能放在浏览器里。
