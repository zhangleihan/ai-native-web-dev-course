# 实践练习：部署与持续集成：可复现环境和数据生命周期

## 输入与准备

准备可运行的 Docker/Compose 骨架及所需依赖，也可以使用已有项目的容器配置。

## 已提供的实验骨架

使用本仓库[案例库实验](labs/course-lab/README.md)，按[第11讲任务单](labs/course-lab/WORKSHEETS.md)定位对应文件。先运行参考实现并解释数据流，再完成本讲增量任务。数据库与 Docker 实验需要在具备相应环境的计算机上运行。

## 操作步骤

核对监听地址和服务名；构建启动；创建记录后重建应用容器；检查数据仍在及秘密未打包。

## 结果检查与练习成果

提供启动命令、访问地址和卷说明；应用重建不丢数据；清楚区分 stop、重建和删除卷。

提交实现或设计产物，以及一条实际观察结果。失败时保留请求、错误信息与已排查的层级；不只提交“已完成”截图。所有实验均使用测试数据。

## 学习自检

完成练习后，检查自己能否做到：说明镜像与容器；区分代码、配置和持久数据；设计失败即停止的 CI 检查。若暂时无法运行，记录缺少的依赖与错误信息，待环境具备后补做验证；阅读参考结果不能代替亲自运行。
