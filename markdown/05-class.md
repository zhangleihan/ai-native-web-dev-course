# 实践练习：Express API：校验、资源与错误边界

## 输入与准备

Node/npm 与隔离练习目录；正文 server.cjs。

## 已提供的实验骨架

使用本仓库[案例库实验](labs/course-lab/README.md)，按[第5讲任务单](labs/course-lab/WORKSHEETS.md)定位对应文件。先运行参考实现并解释数据流，再完成本讲增量任务。数据库与 Docker 实验需要在具备相应环境的计算机上运行。

## 操作步骤

启动 API； POST 创建并 GET 查询；发送空标题、非法难度、坏 JSON；重启观察数据丢失。

## 结果检查与练习成果

成功创建返回 201 和 Location；非法输入 400；列表包装为 items/total；说明数组不是数据库。
