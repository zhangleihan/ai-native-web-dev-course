# 课堂练习：测试：从需求到可重复的失败证据

## 输入与准备

已启动的隔离测试 API 与正文 smoke.cjs；加认证项目准备登录辅助函数。

## 已提供的实验骨架

使用本仓库[案例库实验](labs/course-lab/README.md)，按[第10讲任务单](labs/course-lab/WORKSHEETS.md)定位对应文件。先运行参考实现并解释数据流，再完成本讲增量任务。真实数据库与Docker验证仍需要授课机具备对应环境。

## 操作步骤

10 分钟运行冒烟检查；10 分钟故意破坏空列表状态码；10 分钟恢复并增加一项权限断言；10 分钟检查测试库和清理策略。

## 验收与交付

至少一条测试先失败再通过；断言涉及状态/数据效果；记录命令、结果和 mock 边界。

提交实现或设计产物，以及一条实际观察结果。失败时保留请求、错误信息与已排查的层级；不只提交“已完成”截图。所有实验均使用测试数据。

## 出口检查

对照以下能力逐项演示并解释：为核心需求选择测试层级；写出成功与失败断言；区分软件测试和模型评估。遇到环境阻断时记录阻断点并使用教师演示环境验证，明确区分亲自执行和观察演示。
