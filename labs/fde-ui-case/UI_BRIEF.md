# FDE UI 需求情境包

## 用户与目标

项目成员需要从行业案例出发，完成业务发现、问题定义、方案设计、智能体运行与评测。教师、导师和管理员为源产品中的演示角色；角色切换不代表认证已经实现。

## 核心流程

案例库 → 通信案例详情 → 通信项目 → 访谈与洞察确认 → 问题定义 → 方案设计 → 启动运行 → 查看审批 → 批准/拒绝 → 结果与评测。

## 已有工程

复用 web/package.json 与锁文件中的 Next.js、React、TypeScript、Ant Design、React Flow。读取 web/src/app、components、lib/store.tsx、lib/theme.ts、mock；不修改不相关的数据处理和项目立项文件。

## 页面规则

AppShell 统一导航与项目上下文；PageHead 统一标题与主操作；StageBar 展示阶段；FlowCanvas 封装关系图；CopilotDrawer 提供辅助建议。按任务选择卡片、三栏分析区、图形画布或轨迹详情，不机械复用同一个表格模板。

## 状态与边界

项目、访谈成果、运行与审批跨页共享；关键词、标签页和草稿局部保存。原型只使用模拟数据和脚本，不调用真实工具。明确项目切换、刷新、返回页面时哪些状态会重置。

## 完成标准

导航与项目一致；接受/拒绝改变目标洞察；方案画布可展示节点与关系；运行与轨迹读取同一状态；审批分支可解释。不能把现有图形展示当作已经完成持久化编辑器。检查桌面布局、窄屏、键盘操作、空结果与错误反馈。
