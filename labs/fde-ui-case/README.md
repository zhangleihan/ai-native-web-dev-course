# FDE 工作台：氛围编程 UI 案例资料

本目录配合第四讲的 `#/part/4/g` 与 `#/part/4/h`，提供从 FDE-Workspace/web 复制的完整前端，可独立安装和运行。源码、模拟数据与配置均保存在本目录，无需原项目目录。

- UI_BRIEF.md：第一轮提供给 AI 的需求情境包。
- PROMPTS.md：从需求到交互的分轮复现提示词。
- SOURCE_MAP.md：已核对源码、截图来源及实现边界。
- ACCEPTANCE.md：运行时填写的检查表，未运行项不得预填通过。

从课程仓库根目录启动：

```bash
cd labs/fde-ui-case
npm ci
npm run typecheck
npm run dev
```

默认本地端口3100；避免强制结束其他服务。FDE 当前为内存模拟，刷新及项目切换会重新加载演示状态；没有真实认证、模型调用、数据库或部署服务。

本目录的提示词是基于当前源码重建的教学模板，不是原始历史对话。原项目与其截图沿用原授权范围，教材不另行授予公开再分发许可。

## 工程结构

- `src/app`：工作台、案例、项目各阶段和管理页面。
- `src/components`：导航外壳、画布与共享组件。
- `src/lib`：主题、共享状态和工具函数。
- `src/mock`：完整演示数据。

使用 Node.js 20，打开 http://127.0.0.1:3100。端口占用时使用 `npm run dev -- -p 3101`。生产预览执行 `npm run build` 后运行 `npm start`。复制时保留原依赖锁文件，未复制 node_modules、.next 或构建缓存。启动脚本默认只监听本机。

## 依赖说明

本副本保留源项目版本以复现界面。安装提示 Next.js 14.2.16 存在已知安全问题，部署到公网前需单独升级并回归验证。锁文件中的 eslint-visitor-keys 要求 Node.js 20.19+（或22.13+）；建议使用满足该要求的版本。
