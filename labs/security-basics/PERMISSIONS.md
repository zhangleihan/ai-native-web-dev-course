# 案例与运行权限矩阵

写请求前提：来源、CSRF及字段有效；否则会提前在相应层被拒绝。

| 动作 | 匿名 | 本人/普通用户 | 其他普通用户 | 管理员 |
|---|---|---|---|---|
| GET公开案例 | 200 | 200 | 200 | 200 |
| POST创建案例 | 401 | 201，owner为自己 | 201，owner为自己 | 201，owner为自己 |
| PATCH本人案例 | 401 | 200 | 403 | 200 |
| GET本人运行 | 401 | 200 | 403 | 200 |
| POST审批 | 401 | 403 | 403 | 按状态检查后200或409 |
| POST退出 | 销毁当前匿名会话后204 | 销毁当前会话后204 | 不得销毁别人的会话 | 销毁当前会话后204 |

合法UUID但资源不存在按契约404，格式错误400。创建夹带ownerId或role不会改变服务端身份；综合实验忽略多余字段，独立Express入门实验则拒绝多余字段，二者不要混用预期。

所有者来自服务端记录，管理员标志来自服务端用户。前端传来的同名字段不是事实来源。角色降权测试直接改变隔离夹具，再验证下一次请求；没有提供客户端修改角色接口。
