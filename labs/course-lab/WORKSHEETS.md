# 分讲实验任务单

参考实现已走通主线。学生先运行、解释并验证，再完成下面的增量任务；不能把“克隆后可以打开”当作全部作业。教师可按班级进度选取任务，不要求一讲改完所有扩展。

| 讲次 | 课内观察/操作 | 学生增量任务 | 验收证据 |
|---|---|---|---|
| 1–2 | Network中追踪筛选与创建 | 写出成功/空结果/失败请求 | 方法、状态与响应匹配 |
| 3 | 比较原生HTML例子和实验DOM | 改进一个控件label或键盘路径 | 键盘演示及原因 |

| 6 | 阅读SQL约束和参数化查询 | 持久模式增加summary字段迁移 | 数据迁移可复现，旧数据可读 |
| 7 | 快速切换筛选，停止API | 增加独立重试按钮或请求id | 失败非空结果，旧结果不覆盖新结果 |

## 课堂最小通过条件

运行与解释对应核心行为即达到课堂目标；表中增量可放到课后。第6/8/14讲先理解已有骨架再补一个具体行为，不从零搭建数据库/认证/harness。已完成的参考实现不能替代学生解释能力。

## 教师验收脚本

在两个不同浏览器会话或依次退出/登录中切换alice与admin。不要仅切换前端显示的用户名；必须查看 `/api/session` 确認服务器身份。任何修改都在新建练习库中执行。

1. 无行业匹配返回200及空数组；非法difficulty返回400。
2. alice修改bob案例返回403；随后GET确认原值未变。
3. mock坏证据返回502；超时返回504；浏览器有错误说明。
4. alice不能批准自己的提案；admin拒绝后无工单。
5. admin对同一待审批run并发POST两次approve，最终仅一张工单。
6. 在PostgreSQL模式重启服务/重建web后记录仍在；memory模式应丢失。

第5项自动测试覆盖了内存适配器；SQL单连接测试覆盖事务与顺序重放。真实PostgreSQL并发检查不能据此省略。

## 常见故障

| 现象 | 先检查 |
|---|---|
| 页面404或空白 | npm run build是否成功；打开的是3001实验站而非8766教材 |
| 登录写请求报ORIGIN | PUBLIC_ORIGIN与地址栏协议、主机、端口是否一致 |
| 口令修改后数据库账号仍登录失败 | seed不覆盖已有账号；确认使用初次建库时口令 |
| 缺session/schema表 | 是否先migrate；DATABASE_URL是否为该练习库 |
| 容器启动但浏览器访问失败 | HOST=0.0.0.0、端口发布、db健康与启动日志 |
| SSE没有持续token输出 | 此实验推送trace/状态，未连接真实模型token流 |
| 重启数据丢失 | health显示memory还是postgres；数据库卷是否保留 |
